Der WPorbit-Agent auf dem Server prüft jetzt, ob eine Website Mails versendet. Das Ergebnis steht im Team-Dashboard im Tab „Mail“. Die Testmail geht über den normalen Mailweg der Website an eine fest eingetragene WPorbit-Adresse, höchstens eine alle 10 Minuten.

Für Websites, die schon überwacht werden: einmal „Lesezugang neu einrichten…“ im Menü des Projekts ausführen.
